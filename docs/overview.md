# ATENOR System: contexto y alcance

ATENOR System es una plataforma multinegocio del ecosistema Salva Systems. Busca reunir comunicación, clientes, pedidos y operación en un mismo producto, con automatizaciones e inteligencia artificial configurable según necesidades del negocio.

## Estado documentado

SaaS en evolución · desde marzo de 2026. Desde marzo de 2026. Aproximadamente **cuatro implementaciones activas en negocios del sur de Tamaulipas**. El producto continúa evolucionando como SaaS reutilizable. Este repositorio reúne documentación pública de producto y alcance.

Lehi Salvador — liderazgo de producto, levantamiento de requerimientos, reglas de negocio, diseño de workflows, planificación, pruebas, coordinación del desarrollo y validación con negocios.

Esta documentación amplía la información proporcionada por el responsable del producto. Los criterios y siguientes pasos de la hoja de ruta son propuestas de documentación pública; no compromisos de entrega ni capacidades adicionales implementadas.

## Flujo de referencia

1. Conversación de negocio.
2. Contexto del cliente.
3. Pedido u operación.
4. Workflow y reglas.
5. Validación con el negocio.

El flujo describe el contexto del producto. No define una API, integración ni procedimiento productivo listo para ejecutar.

## Vocabulario

| Concepto | Significado en este contexto |
| --- | --- |
| Negocio | Contexto operativo independiente dentro del modelo multinegocio. |
| Conversación | Interacción de WhatsApp que debe conservar contexto útil. |
| Cliente | Entidad relacionada con comunicación y operación del negocio. |
| Pedido | Solicitud vinculada con reglas y seguimiento operativo. |
| Workflow | Secuencia de pasos y automatizaciones definida para un negocio. |
| IA configurable | Capacidad ajustada al contexto y reglas del negocio. |

## Límites de publicación

- Se presenta el producto SaaS; no se publican implementaciones activas, conversaciones ni datos de clientes.
- Aproximadamente cuatro implementaciones activas es el estado comunicado, no una métrica actualizada automáticamente.
- El aislamiento entre negocios y la autorización de automatizaciones son criterios para revisar, no garantías técnicas acreditadas por este repositorio.

Los sistemas reales y su infraestructura se administran por separado. Este repositorio no contiene instrucciones para acceder a clientes o desplegar aplicaciones.
